# W&B MLOps exercises (archived)

This repository contains exercises completed while learning Weights & Biases
in 2023. It is preserved as a historical snapshot and is no longer maintained.

The environment targets Python 3.9 and older versions of the ML libraries, so
it should not be treated as a current setup guide.

## Contents

- Exploratory data analysis
- Dataset splitting
- Baseline training and evaluation
- Weights & Biases experiment tracking

For new work, start from the current
[Weights & Biases documentation](https://docs.wandb.ai/) instead.
